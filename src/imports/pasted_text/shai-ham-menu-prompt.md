Figma AI Prompt — Shai Ham (شاي هام) Menu Website
How to use this
Open Figma → Figma AI / "Make" (or First Draft).
Upload the logo file and the menu photos as reference/attached images when you start the prompt (Figma AI can read attached images for colors, style, and text).
Paste the Main Prompt below as your first instruction.
Use the Follow-up Prompts section afterward to refine section by section.
Main Prompt (paste this into Figma AI)
Design a premium, mobile-first, single-page digital menu website for a tea brand called "Shai Ham" (شاي هام), written in Arabic. The site's only purpose is to showcase the shop's menu beautifully — this is not an e-commerce store, just a digital menu/lookbook.

BRAND & VISUAL IDENTITY
- I am attaching the brand logo. Extract the exact colors from the logo and use them as the core palette (primary, accent, and neutral/background tones). Do not invent unrelated colors.
- Study the ornamental details, symbols, or decorative patterns inside the logo (e.g. line work, botanical motifs, geometric or Arabic-calligraphy-inspired shapes) and reuse simplified versions of them as background textures, section dividers, icons, or corner ornaments throughout the site — so the whole site feels like a natural extension of the logo, not a generic template.
- Typography: choose an elegant Arabic typeface whose letterforms feel close in spirit to the logo's lettering style (e.g. if the logo is calligraphic/traditional, use a refined Arabic serif or Naskh-style display font for headings; if the logo is modern/minimal, use a clean modern Arabic sans with generous spacing). Pair it with a simple, highly legible Arabic font for menu item names and prices.
- Overall mood: luxurious, warm, calm, high-end tea-house feeling — think boutique tea salons, not a fast-food menu. Generous white/negative space, soft shadows, subtle gold or metallic accent line details, refined photography treatment.

LANGUAGE & LAYOUT DIRECTION
- All text/UI in Arabic, right-to-left (RTL) layout.
- Design for mobile screen size first (390–430px width frame), as if it will be opened from a QR code on a customer's phone.

PAGE STRUCTURE
1. Hero section — logo centered/prominent, brand name "شاي هام" in large display type, a short elegant tagline placeholder, soft background using logo colors/patterns.
2. About/intro strip — one short line about the brand's character (placeholder text, e.g. "تجربة شاي فاخرة" style).
3. Menu categories — organize into clear categories (e.g. شاي ساخن، شاي مثلج، مشروبات خاصة، حلويات — adjust categories to match the attached menu photos). Each category has its own elegant header with a small ornamental icon derived from the logo motifs.
4. Menu items — for each item show: name, short description (optional, placeholder if unknown), and a price. For prices, generate placeholder values grouped by tiers based on how premium/complex each item looks in the reference menu photos (e.g. simple hot tea = lower tier price, specialty/signature drinks with more ingredients = higher tier price) — clearly mark these as placeholder prices I will edit later, using a consistent, elegant currency style.
5. Product cards should have a refined, editorial look — not app-store style cards. Use thin borders, soft dividers, or an elegant list layout instead of heavy boxed cards.
6. Footer — social icons, working hours placeholder, location placeholder, and the logo motif repeated subtly as a closing ornament.

DELIVERABLE
- One cohesive, scrollable mobile page.
- Consistent spacing system and a clear visual hierarchy between category titles, item names, descriptions, and prices.
- Make it feel premium, editorial, and true to the Shai Ham brand identity — not a generic template.
Follow-up Prompts (use after the first draft, one at a time)

Refine the hero:

Make the hero section feel more premium — enlarge the logo slightly, add a subtle ornamental pattern in the background using the logo's motifs at low opacity, and improve spacing so the brand name breathes more.

Refine menu cards:

Redesign the menu item layout to feel more editorial and boutique — remove heavy card boxes, use elegant divider lines between items instead, and align prices neatly to the left/right depending on RTL flow.

Add category icons:

Create small minimal line-icons for each menu category, inspired by the shapes/patterns found in the logo, and place them next to each category title.

Polish typography:

Adjust the Arabic typography scale: increase contrast between category headers, item names, and prices so the hierarchy is instantly clear while keeping the elegant tone.

Color/contrast pass:

Do a final pass to make sure all colors are pulled directly from the logo palette, contrast is accessible for reading on mobile, and the gold/accent color is used sparingly for emphasis only (icons, dividers, prices).
Notes for you (not part of the Figma prompt)
Attach the logo image and a few clear menu photos directly in the Figma AI chat before sending the Main Prompt — this lets it actually read the real colors, motifs, and menu items instead of guessing.
Because you said the real prices will change later, the prompt asks Figma to generate placeholder tiered prices based on how premium each item looks — you can swap in real numbers afterward without changing the layout.
If Figma's output ignores the logo colors/motifs, resend the "Color/contrast pass" follow-up prompt with the logo image attached again — it sometimes needs a second nudge to actually sample the image.
